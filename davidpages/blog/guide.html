Ok so here's how we're sort of organizing everything:

house-website is the root directory, so when the website is live, the url to house-website/whatever will be gayhouse.online/whatever.

In the root directory, we have a bunch of shit rn, it's just the communal pages and resources and stuff. (I'll probably do some organizing into folders later.) Each person has a dedicated folder, /[yourname]pages, where you can put whatever you want. A structure like this has been working well for me:

  • davidpages
    • index.html (homepage)
    • style.css (style)
    • img directory (images)
    • gallery (...then any other pages each get their own folder,)
      • index.html (with their own html,)
      • style.css (css,)
      • img (etc.)

So here's how html works

An html file is where you list all the stuff ("elements") you want to appear on the page. Theres a bunch of different kinds of elements like

Name HTML code Appearance on the webpage
Heading <h1>PHOTOS</h1> Note: h1 is biggest, h2 is smaller, h3, h4, etc.

PHOTOS
Paragraph <p>I will now expound the virtues of barefootedness; ...</p>

I will now expound the virtues of barefootedness; ...
Image <img src="img/meal.jpg"> Note: no closing tag
Link <a href="https://en.wikipedia.org/wiki/Special:Random">random wikipedia article</a> random wikipedia article
